# 已实现清单

> 状态口径：**已实现** = 代码已写好且经过程序自测；**已验证** = 有真实执行输出作为证据（见《已验证清单》）。
> 本清单只列已实现的部分，未完成项见《未完成清单》。

## 一、播放器（正式产品，纯静态、无模型调用）

- `player/index.html` + `player/js/{app.js, player.js, storage.js, share.js}` + `player/css/app.css`
- 首页：真实故事卡片、题材筛选、继续上次进度、随机选故事入口。**不提供在线 AI 生成输入框**。
- 故事详情页：标题、题材、简介、预计时长、结局数量、人物表。
- 阅读页：短段落正文、2–3 个选项、选项点击即进入下一节点、**立即显示完整正文**（无逐字动画）。
- 结局页：故事结果、**关键选择回顾**、已解锁结局进度、重玩、返回故事库、分享。
- 分享：静态哈希深链（`#/s/<storyId>`），URL 中**不含**任何原始聊天或编辑凭据。
- 进度：localStorage 本地保存，无需账号；刷新后恢复。
- 无障碍：减少动态效果选项（`prefers-reduced-motion` + 手动开关）。
- 资源：系统字体栈 + CSS 程序绘制图案，**无外链字体/图片**。

## 二、共享结构（冻结 v1）

- `shared/schema.js`：字段白名单、长度/数量上限、`SCHEMA_VERSION`。
- `shared/runtime.js`：状态与条件的声明式求值（bool/int/enum 有限枚举，**不接受任意表达式**）。
- `shared/validate.js`（477 行）：storyId/startNodeId 存在性、节点 ID 唯一、全节点从起点可达、
  全结局可达、非结局节点必须有选项、初版无环、路径长度上限、选项文字不重复、伪分支检测、
  人物/道具引用一致性、正文长度上下限、以及 **带状态的可达性验证**（不只检查图上的连线）。

## 三、内部生产流水线（不进入发布包）

`tools/content/produce.cjs` 实现任务书第 4 节的完整环节链：

1. **策划** `stepPlan`：产出 3 个不同核心冲突的提案。
2. **结构设计** `stepSkeleton`：由 `tools/content/shapes.cjs` 按层生成 DAG（**图不由模型生成**），
   模型只填每层的场景、目的、选项文字。
3. **对白写作** `stepWrite`：**正序**（按层从浅到深）小批量写正文。
4. **程序检查** `stepProgramCheck` + `tools/content/check.cjs`：结构校验 + 机械修复（超长截断、非法变量剔除）。
5. **独立编辑审核** `stepEditorReview`：独立请求，要求逐字证据。
6. **路径审核** `stepPathReview`：抽样阅读实际游玩路径文本。
7. **定点修复** `stepFix`：只修失败节点，**硬上限 2 轮**。
8. **定点回归** `stepTargetedRegression`：只复验被修节点 + 邻居。
9. **程序侧剧情检查**：`merges.cjs`（合并点一致性）、`props.cjs`（道具铺垫）、`facts.cjs`（同层同场）。
10. **验收门** `finalize`：结构合法 **且** 去重后无残留 blocker/major → 通过；否则隔离。

配套工具：

- `tools/llm.cjs`：预算闸门、并发闸门、有界退避、用量日志、JSON 截断无损修复、IPv4 优先。
- `tools/content/batch.cjs`：有界批次队列、故事级断点续跑、隔离后重试第二候选（上限 2）。
- `tools/content/plan-b.cjs`：B 档计划生成（8 题材 × 10）。
- `tools/content/evalset.cjs`：评测集生成。
- `tools/verify/coverage.cjs`、`tools/verify/path-audit.cjs`：覆盖报告与逐路径语义审读。
- `tools/report.cjs`：批量与质量报告生成。
- `tools/pack.cjs`：发布包 / 离线包打包 + 密钥样式扫描。

## 六、关键实现决定（影响正确性，记录备查）

- **图结构不由模型生成**：由 `shapes.cjs` 按层构造 DAG，天然无环、全可达、每节点 2–3 选项、末层恰 3 结局。
- **形状池按实测收敛率收敛**：默认 `grid12`(6 层/32 路径)、`grid14`(7 层/64 路径)；8 层/128 路径移入 `SHAPES_BACKLOG`（实测反复不收敛）。
- **合并点纪律**：同层节点不得改变共享物件的形态（甜/咸、整盘/切块、手里的餐具），差异只允许体现在人物态度上。
  这是「下游合并点无论怎么写都会与其中一条不符」这类反复隔离的根本解法。
- **写作顺序正序**（按层从浅到深），使合并点能看到上游实际文本。
- **定点回归取代全篇重审**：修复后只复验被改节点 + 邻居，符合任务书第 4 节第 7 步。
- **`--no-fix` 开关**：人工定稿后跳过自动修复，验收门与全部程序检查照常执行。
- **审核提示防推理吃预算**：明确「直接写 JSON，不做前置分析」「最多 2 条」「每条必须给逐字 evidence」。
