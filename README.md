- 端口 **8790**（与「梗一下」的 8765 完全独立，不共用目录、数据库或密钥文件）
- 工程根目录：`<工程根>\`

## 一、如何运行

### 1. 本地预览（开发/验收）
```bash
node server/serve.cjs                 # → http://127.0.0.1:8790/player/index.html
```
纯静态服务，无任何密钥或模型逻辑。

### 2. 静态发布包（可托管到任意静态服务器）
```bash
node tools/pack.cjs                   # 生成 publish/ 与 outputs/如果当时-离线包.zip
```
`publish/` 即完整站点：播放器 + 故事文件 + 索引。不含 `.env`、不含生成工具。
直接用任意静态服务器指向 `publish/` 即可（`publish/index.html` 就是故事库首页）。

### 3. 离线包
解压 `outputs/如果当时-离线包.zip`，双击 `启动-离线游玩.cmd`（需 Node.js 18+），
或 `node offline-server.cjs` → http://127.0.0.1:8791/ 。
离线包内含播放器、全部故事与一个微型静态服务器，**不需要网络**。

## 二、内容生产（仅开发期使用）

```bash
# 结构设计（图形由程序生成）+ 对白写作 + 程序检查 + 独立审核 + 定点修复
node tools/content/produce.cjs --genre travel --id sc-0004 --premium

# 按计划批量生产（有界队列 / 断点恢复 / 自动暂停 / 每批报告）

# 仅发布通过校验的故事并重建索引
node tools/build-index.cjs

# 生成评测集
node tools/content/evalset.cjs --count 2000
```

密钥只从环境变量或 `LLM_API_KEY_FILE` 指向的本机文件读取（见 `.env.example`），
**不复制明文、不写入任何产物、不进入发布包**。

## 四、故事结构（schemaVersion 1）

```json
{
  "schemaVersion": 1, "storyId": "sc-0004", "title": "…", "genreId": "travel",
  "tagline": "…", "summary": "…", "estimatedMinutes": 4,
  "cover": { "pattern": "grid", "hue": 205 }, "tags": ["…"],
  "characters": [{ "id": "c1", "name": "…", "desc": "…" }],
  "vars": [], "contentVersion": 1,
  "startNodeId": "n1",
  "nodes": [
    { "id": "n1", "text": "…", "choices": [{ "text": "…", "to": "n2" }] },
    { "id": "n10", "text": "…", "ending": { "id": "e1", "title": "…", "kind": "happy" } }
  ],
  "endings": [{ "id": "e1", "nodeId": "n10", "title": "…", "kind": "happy" }]
}
```

运行时校验（播放器端 `validateBasic` + 生产端 `shared/validate.js`）覆盖：
字段类型、长度、数量、ID 唯一性、目标节点存在性、起点存在、全部节点可达、结局可达、
非结局节点必有选项、无循环、路径长度、选项文字长度与重复、伪分支、结局实质区别、
敏感信息与联系方式。**任何校验失败的故事一律不进入播放器目录。**

### 旧故事版本兼容
`schemaVersion` 为硬校验项：播放器只加载与当前版本一致的故事；
旧版本故事继续按原版本规则加载（保留文件即可），不会被新规则重新校验或破坏。
批量生产前结构已冻结在 v1，避免大批内容生成后无法加载。

## 五、状态与条件（有限枚举，无可执行表达式）
`vars` 仅允许 `bool` / `int`（带 `min`/`max`）/ `enum`（≥2 个取值）；
节点条件为声明式 `{ var, op, value }`，运行时只做比较运算，**不接受任意表达式或代码执行**。
启用状态的图必须通过「带状态可达性」校验（`validate.js` 按（节点 × 状态）元组做实际可达性检查，
不只检查连线）。

## 六、分享与进度
- 分享：哈希深链 `#/s/<storyId>`，只包含故事 ID，不含任何私人内容或凭据。
- 进度与结局解锁：浏览器 `localStorage`，刷新后可恢复；无需账号系统。

## 七、离线说明
在线站点需要先联网取回站点文件；**全部文件取回后**，已缓存/已下载的内容可断网游玩。
离线包（zip）则完全不需要网络。不宣称首次访问即可离线。
